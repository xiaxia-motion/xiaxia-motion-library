# 灯泡拨动开关

来自「夏夏的AI灵感」2026-11-18 发布的《复古橡皮管 UI》。本包为原版 C++ 绘制函数，演示窗口长 1.49 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

滑柄横移 97 单位，到位后轻微弹过头，灯丝和放射线同步。 原角色时钟为 60 帧/秒和 128 BPM。离线图集为 24 帧/秒，原始函数支持任意时刻与目标分辨率。

源工程为「纸上放映厅 · 标准首尾 v4 沿用的正文角色函数」。时钟从 5.940 秒取到 7.430 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

单独展示角色并居中取景。搜索、片单和放映设备的小图使用程序绘制的月亮替代。

## 工具、插件与实现

C++17、Cairo 1.18.4、pkg-config；重新生成预览使用 Python 3 与 Pillow。浏览器端为原函数逐帧绘制的图集。

[Cairo](https://www.cairographics.org/) · [Pillow](https://pillow.readthedocs.io/)

## 重绘或导出高清帧

打开 component.cpp 修改绘制逻辑。直接预览用随包的 WebP 图集。重新生成时需要 C++17 编译器、Cairo 开发库、pkg-config、Python 3 和 Pillow。macOS 可用 Homebrew 安装 cairo 和 pkg-config；Linux 可用系统包管理器安装相应开发包。

在这个目录打开终端，运行下面的命令。第一个命令会重新生成浏览器分帧预览，第二个命令只导出一张指定时刻的无损 PNG。原坐标按 4∶3 等比放大。

~~~sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install Pillow
python3 render.py
python3 render.py 6.760 1920 1440 frame.png
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

滑柄横移 97 单位，到位后轻微弹过头，灯丝和放射线同步。 以暖纸、深咖轮廓、朱红和芥末黄建立旧戏院的橡皮管角色。身体轮廓、眼睛方向、手套接触点都依照 component.cpp 的动作求值。
