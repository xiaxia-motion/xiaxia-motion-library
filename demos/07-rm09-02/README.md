# 固定指针色温滑尺

来自「夏夏的AI灵感」2026-11-10 发布的《滑杆调节》。本包为原版核心提取，演示窗口长 4.30 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

想自己操作，可以打开 [互动版](interactive/index.html)。按住炭灰标尺横向拖动，指针始终固定在中央；向左拉刻度会提高色温。 下方原生滑杆和主滑尺的方向键都能调节，范围 2500–7500 K，步长 50 K。 点击复位回到 3700 K；这是数值示例，不调整显示器。

## 画面与时间

单组件截取帧区间 [342, 600)，每秒 60 帧。可操作版的具体输入见下文。

源工程为「滑杆调节定稿独立动作」。时钟从 5.700 秒取到 10.000 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

按原组件绘制函数及发布版动作曲线拆分，移除栏目包装。示例摄影替换为程序山景。曝光、色温、旋转、对比与原手柄仍在同一步进中计算。

## 工具、插件与实现

原片使用 React 19.2.3、Remotion 4.0.539、SVG；离线入口复用绘制函数和 React，逐帧时间由浏览器驱动。React 与 ReactDOM 随包附 MIT 许可。

[React](https://react.dev/) · [Remotion](https://www.remotion.dev/docs/)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./07-rm09-02/index.html" title="固定指针色温滑尺" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

如要嵌入实操入口，可把上面的地址换成 07-rm09-02/interactive/index.html。互动规则和对应提示词也放在 interactive 目录。

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。 用鼠标或键盘重复执行上面的实际操作。

## 复刻提示词

请用 React 和 SVG 单独实现「固定指针色温滑尺」。中央指针保持不动，整条色温刻度从下方滑过。参考 effect.js 中的原始绘图坐标、曲线与取帧区间，在一个 4∶3 容器按每秒 60 帧演示。保留动作前的初态、运动中的过渡与结束后的稳定姿势，不能用静图切换代替。

真实操作版要让访客自己触发同样的反馈。按住炭灰标尺横向拖动，指针始终固定在中央；向左拉刻度会提高色温。 下方原生滑杆和主滑尺的方向键都能调节，范围 2500–7500 K，步长 50 K。 点击复位回到 3700 K；这是数值示例，不调整显示器。 将操作、绘制与计时放在各自容器中，支持重新操作；照着 interactive 文件夹的输入处理实现。
