# 银色卡片抛起翻转

来自「夏夏的AI灵感」2026-11-17 发布的《VibeCoding 八工具》。本包为原版核心提取，演示窗口长 1.25 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

卡片沿抛物线上升和回落，在 1.1 秒中绕自身对角轴转十圈。用法向量切换卡片正反，接触桌面后仅剩短暂震动。

源工程为「VibeCoding 八种工具 · v24」。时钟从 0.000 秒取到 1.250 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留卡面、几何、双面判断和动线，用系统字体替代成片字体。

## 工具、插件与实现

HTML/CSS 3D、原生 JavaScript。原片使用 GSAP 作为时间线；本包直接调用原片的逐帧 render。

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./14-card-toss/index.html" title="银色卡片抛起翻转" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

卡片沿抛物线上升和回落，在 1.1 秒中绕自身对角轴转十圈。用法向量切换卡片正反，接触桌面后仅剩短暂震动。 独立展示这个动作，遵循下载包的取景、时间范围和缓动，提供播放、暂停、重播与定位。
