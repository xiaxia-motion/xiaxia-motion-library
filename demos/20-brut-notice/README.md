# 印刷辊展开票根并盖章

定稿取样 02:03.23–02:05.20。起止逻辑帧为 3697 至 3756（末帧不含），原时钟每秒 30 单位，成片与预览按每秒 60 帧取样。

## 打开与操作

1. 下载并完整解压本组 ZIP，双击 index.html。现代桌面浏览器可离线使用。
2. 点「暂停」，拖动时间条检查动作。点「回到开头」或「播放」可重复观察。减弱动态效果的系统偏好会让页面从暂停开始。
3. 点「自己操作」。点击右侧票根或按「盖章」，观察副券上勾印回弹。 点「返回原动作」可继续核对演示。

## 文件与修改办法

- effect.js 是可读的主源码，可直接编辑。搜索 showcase、tour 定位绘制函数。操作模式另外调用 solo 和 drawFace。
- settings.js 的 speed 是播放倍率，默认为 1。start / end 的单位是秒，fps 的单位是帧/秒。保持本组时段，可以用 speed 调快或放慢。绘制使用固定逻辑坐标，网页等比缩放。
- 本组可调项包括印刷辊位置、票面字段与盖章回弹。先把整个文件夹和「提示词.txt」交给 AI，说明只调整其中哪一项。修改后刷新 index.html 可直接对照。
- 在自己的网页中依照 index.html 保留本组脚本的加载顺序；NeoEffect.ready() 完成后，对二维画布调用 NeoEffect.draw(ctx, 原片秒数)。此页面也提供 window.singleEffect.seek(组件内秒数)、play() 和 pause()。
- media.js 将 WebP 作为 data URL 内嵌。换图时，用新图的 data:image/webp;base64 数据替换原键对应的值，并更新图片署名。

## 调用工具与规格

原片使用 React 19.2.3 与 Remotion 4.0.539 编排，Chromium 逐帧绘制，FFmpeg 编码。独立预览以 Canvas 2D 和浏览器帧钟运行。 实际操作由原生表单和 Pointer Events 接收鼠标、触摸及键盘输入。 原片交付为 3840 × 2880、60 帧/秒。随包预览以静音方式绘制，使用系统中文字体。

## 复刻提示词

为 4:3 的浏览器预览实现「印刷辊展开票根并盖章」。将蓝色进度轨卷成印刷辊，同一条接缝后展开票根。周日主舞台 20:30 开演，20:10 振动提醒；黑色勾印落在珊瑚色副券上。 使用 1440 × 1080 的逻辑画布，按 60 帧/秒采样，演示约 1.9667 秒。让印刷辊位置、票面字段与盖章回弹可调，拖动时间条到任一位置都能重现同一画面。 同时提供可用鼠标和键盘操作的独立控件。点击右侧票根或按「盖章」，观察副券上勾印回弹。
