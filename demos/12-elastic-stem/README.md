# 蒲公英弹性入场

来自「夏夏的AI灵感」2026-11-15 发布的《蒲公英烟花》。本包为原版核心提取，演示窗口长 3.05 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

花茎以 1/240 秒子步积分。画面为 4:3；每秒 60 帧，预览 800×600。

源工程为「蒲公英花瓣烟花 · v12 定稿」。时钟从 0.000 秒取到 3.050 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

移除账号落款和配乐。多阶段共享同一花头，播放器只开放本组动作。

## 工具、插件与实现

Three.js r180、WebGL2、InstancedMesh；原片三次运动模糊采样，浏览器示例单次采样。

[Three.js](https://threejs.org/docs/)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./12-elastic-stem/index.html" title="蒲公英弹性入场" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

一株有柔性花茎的蒲公英从侧边弹入，顶端发生延迟回摆，纸面浮影保持稳定。 用花茎求解器、曲面花瓣几何及固定随机数生成器生成画面。
