# 星尘成形

来自「夏夏的AI灵感」2026-11-07 发布的《四种空间动效》。本包为原版核心提取，演示窗口长 4.50 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

design.js / markPaths 三条轮廓决定粒子的终点。 光晕强度 .46、半径 .43、阈值 .72；设计分辨率 1440×1080，预览以 0.6 倍绘制。

源工程为「四种空间动效 · v8 原始三维场景」。时钟从 18.500 秒取到 23.000 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

去掉教程字幕与音轨，保留原项目的程序密度图与原创发光纹理。

## 工具、插件与实现

Three.js 0.180.0，WebGL2，EffectComposer、RenderPass、UnrealBloomPass、OutputPass。原片另用 HyperFrames 0.8.222；此包直接用浏览器时钟。

[Three.js](https://threejs.org/docs/) · [HyperFrames](https://github.com/heygen-com/hyperframes)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./02-dust-to-mark/index.html" title="星尘成形" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

让同一批星尘沿两条弧线回卷成太阳和双山，保持原有颜色和短尾迹。 自建三维场景，使用给定的几何、着色器与镜头；从设置中指定的时间开始，循环这一组效果。
