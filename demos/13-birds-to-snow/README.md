# 鸟群散为立体雪花

来自「夏夏的AI灵感」2026-11-16 发布的《粒子幻境》。本包为原版核心提取，演示窗口长 4.15 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

five-timing.js：正文第 586/60 秒触发雪晶形态。逻辑画幅 4:3，60 帧/秒，预览 960×720；Bloom 强度 .36、半径 .28、阈值 .83。

源工程为「粒子幻境 · 定稿 4K60 五形版」。时钟从 12.767 秒取到 16.917 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

首尾圆环也拆出独立入口。正文动作依赖粒子身份连续性，随包保留共用形变函数。

## 工具、插件与实现

Three.js r180、WebGL2、UnrealBloomPass、浮点 DataTexture 和自定义 GLSL。原工程 HyperFrames 0.9.52 用于录制。

[Three.js](https://threejs.org/docs/) · [HyperFrames](https://github.com/heygen-com/hyperframes)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./13-birds-to-snow/index.html" title="鸟群散为立体雪花" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

飞鸟连续解散成粒子并重组为多枚六向雪晶；镜头升高观察同一粒群。 保持原工程的顶点编号与相机基准，避免硬切或用视频贴片。
