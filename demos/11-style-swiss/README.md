# 瑞士平面主图微晃

来自「夏夏的AI灵感」2026-11-14 发布的《十二种设计风格》。本包为原版核心提取，演示窗口长 2.38 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

1440 × 884 页面；横向 1.8、纵向 2.8 像素；最大转角 1.35°；三个正弦周期分别为 3.2、2.8 和 3.8 秒；首尾缓入归零。

源工程为「给AI换个审美 · v19，瑞士平面」。时钟从 22.800 秒取到 25.180 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留单页静置时的原位微晃。字体使用浏览器本机的中文字体。

## 工具、插件与实现

原片使用 React 19.2.3、Remotion 4.0.539、SVG；离线入口复用绘制函数和 React，逐帧时间由浏览器驱动。React 与 ReactDOM 随包附 MIT 许可。

[React](https://react.dev/) · [Remotion](https://www.remotion.dev/docs/)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./11-style-swiss/index.html" title="瑞士平面主图微晃" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

用严格网格、无衬线字体，统一左对齐，红黑白配色。保留包内页面的构图，主图绕自身中心进行极小幅移动与旋转；文字和背景固定，动作幅度和曲线使用 iconMotionAt。
