# 实体键帽计算

来自「夏夏的AI灵感」2026-11-13 发布的《七种拟物材质》。本包为原版控件提取，演示窗口长 3.20 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

依次按 8、×、6、=；每次下压 0.18 秒，显示屏最终为 48。 控件样式见 material.css，原帧制为 60 帧/秒。

源工程为「七种拟物风格 · v17 定稿（内部 v18）」。时钟从 0.850 秒取到 4.050 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留对应设备的造型，置中取景，独立播放当前示范动作。

## 工具、插件与实现

HTML、CSS、JavaScript。原片使用 HyperFrames 和 GSAP 管理整片时间；独立版使用浏览器直接求同一控制量。

[HyperFrames](https://github.com/heygen-com/hyperframes)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./10-keycap-calculator/index.html" title="实体键帽计算" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

依次按 8、×、6、=；每次下压 0.18 秒，显示屏最终为 48。 沿用源码里的材质、凹槽、圆角和高光。鼠标可操作，播放或重播恢复原始演示。
