# 网页折成玻璃唱片播放器

定稿取样 00:38.27–00:42.13。起止逻辑帧为 1148 至 1264（末帧不含），原时钟每秒 30 单位，成片与预览按每秒 60 帧取样。

## 打开与操作

1. 下载并完整解压本组 ZIP，双击 index.html。现代桌面浏览器可离线使用。 请在浏览器中启用图形加速。
2. 点「暂停」，拖动时间条检查动作。点「回到开头」或「播放」可重复观察。减弱动态效果的系统偏好会让页面从暂停开始。

## 文件与修改办法

- effect.js 是可读的主源码，可直接编辑。搜索 webDeck、poseAt 定位绘制函数。
- settings.js 的 speed 是播放倍率，默认为 1。start / end 的单位是秒，fps 的单位是帧/秒。保持本组时段，可以用 speed 调快或放慢。绘制使用固定逻辑坐标，网页等比缩放。
- 本组可调项包括折面的轴、圆角过渡、阴影扩散与玻璃条。先把整个文件夹和「提示词.txt」交给 AI，说明只调整其中哪一项。修改后刷新 index.html 可直接对照。
- 在自己的网页中依照 index.html 保留本组脚本的加载顺序；NeoEffect.ready() 完成后，对二维画布调用 NeoEffect.draw(ctx, 原片秒数)。此页面也提供 window.singleEffect.seek(组件内秒数)、play() 和 pause()。
- 可在 effect.js 内搜索 makeSamples，自行修改示例网页的排版、文案和配色。

## 调用工具与规格

原片使用 React 19.2.3 与 Remotion 4.0.539 编排，Chromium 逐帧绘制，FFmpeg 编码。独立预览以 Canvas 2D 和浏览器帧钟运行。 本组的三维场景使用 Three.js 0.180.0 与 WebGL 2。 牌面反光改编自 Vanilla Tilt 的光线方向计算。 原片交付为 3840 × 2880、60 帧/秒。随包预览以静音方式绘制，使用系统中文字体。

## 复刻提示词

为 4:3 的浏览器预览实现「网页折成玻璃唱片播放器」。从两排网页中聚焦一张，沿中线翻成唱片播放器；卡面逐渐变圆，从背板抬起并出现软影。让淡紫渐变铺开，再让玻璃播放条掠过唱片。 使用 1440 × 1080 的逻辑画布，按 60 帧/秒采样，演示约 3.8667 秒。让折面的轴、圆角过渡、阴影扩散与玻璃条可调，拖动时间条到任一位置都能重现同一画面。
