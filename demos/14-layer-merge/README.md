# 画面、边框、文字与声纹合层

来自「夏夏的AI灵感」2026-11-17 发布的《VibeCoding 八工具》。本包为原版核心提取，演示窗口长 6.54 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

四层先在各自透视平面错开，间隔 0.25 秒进入；第 2.9 至 5.2 秒合拢为同一画面，随后面板放大。

源工程为「VibeCoding 八种工具 · v24」。时钟从 0.000 秒取到 6.540 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留绘图和排布函数，用源工程的程序图形替代内嵌的整段样片。静态缩略图来自同一段的程序画面。

## 工具、插件与实现

React、SVG、Remotion 原组件，独立预览使用本地 React 和浏览器时钟。

[React](https://react.dev/) · [Remotion](https://www.remotion.dev/docs/)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./14-layer-merge/index.html" title="画面、边框、文字与声纹合层" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。
