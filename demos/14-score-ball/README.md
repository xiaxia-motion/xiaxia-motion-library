# 十三次落音与跟随镜头

来自「夏夏的AI灵感」2026-11-17 发布的《VibeCoding 八工具》。本包为原工程改编提取，演示窗口长 4.70 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

沿五线谱的 13 个符头逐次落球。击中有蓝色扩散环，尾迹沿上一小段抛物线衰减，镜头用单调三次曲线沿谱线跟随。可手动启用随节拍合成的音色。

源工程为「VibeCoding 八种工具 · v24」。时钟从 25.570 秒取到 30.270 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留相机、抛物线、光环和原片的 13 个事件。谱线和符头重新用基础几何绘制，未使用上游样片、曲谱文件或录音。

## 工具、插件与实现

Three.js 0.180.0、Canvas、SVG。《跳动音符》开源项目的求值方式用于原工程。原片用 SuperCollider 合成打击音，听音示例用 Web Audio。

[Three.js](https://threejs.org/docs/) · [跳动音符 · 言说新事](https://github.com/SyanChen7/dancing-notes) · [SuperCollider](https://supercollider.github.io/)

在预览左下角点“开启节拍声音”。试听代码在 sound.js，音高和时间在 score.js，音色示例.scd 可在 SuperCollider 中选中整段运行。两种合成器的音色会有差别。

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./14-score-ball/index.html" title="十三次落音与跟随镜头" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。
