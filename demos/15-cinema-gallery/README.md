# 放映机拉远与错列控件展墙

来自「夏夏的AI灵感」2026-11-18 发布的《复古橡皮管 UI》。本包为原版 C++ 绘制函数，演示窗口长 2.66 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

跟踪银幕中心，放映机卷轴继续运转，同时把画面缩回左上的节目卡，已完成动作的控件错列显现。

源工程为「纸上放映厅 v4 标准首尾」。时钟从 24.990 秒取到 27.650 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

原排版、原控件和原相机。预览用程序纸纹及自绘月亮代替成片的材料底图。

## 工具、插件与实现

C++17、Cairo、Python 3 与 Pillow。浏览器预览播放同一绘图函数生成的 24 帧/秒图集。

[Cairo](https://www.cairographics.org/) · [Pillow](https://pillow.readthedocs.io/)

## 重绘或导出高清帧

打开 component.cpp 修改绘制逻辑。直接预览用随包的 WebP 图集。重新生成时需要 C++17 编译器、Cairo 开发库、pkg-config、Python 3 和 Pillow。macOS 可用 Homebrew 安装 cairo 和 pkg-config；Linux 可用系统包管理器安装相应开发包。

在这个目录打开终端，运行下面的命令。第一个命令会重新生成浏览器分帧预览，第二个命令只导出一张指定时刻的无损 PNG。原坐标按 4∶3 等比放大。

~~~sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install Pillow
python3 render.py
python3 render.py 26.453 1920 1440 frame.png
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

跟踪银幕中心，放映机卷轴继续运转，同时把画面缩回左上的节目卡，已完成动作的控件错列显现。 保持节目的纸色、笔触和角色姿势，镜头沿原坐标连续运动。
