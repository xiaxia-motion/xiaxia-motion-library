# 十二种风格收进作品墙

来自「夏夏的AI灵感」2026-11-14 发布的《十二种设计风格》。本包为原版核心提取，演示窗口长 4.10 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

主页和图标缩进四列三行展示墙，到位以后每一格以不同相位轻轻平移、转动。

源工程为「十二种设计风格 C2 v19」。时钟从 41.350 秒取到 45.450 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

保留发布版时序、图形采样与材质插值。图层压缩为带透明度的 WebP，预览使用系统字体。

## 工具、插件与实现

React、SVG、WebGL 着色器与 Remotion 的原绘图组件。独立版用浏览器时钟，用本地贴图库加载 12 种图标。

[React](https://react.dev/) · [Remotion](https://www.remotion.dev/docs/)

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./11-twelve-grid/index.html" title="十二种风格收进作品墙" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

主页和图标缩进四列三行展示墙，到位以后每一格以不同相位轻轻平移、转动。 使用真实轮廓和同一组图标，保持版面可读，交付可拖动的独立组件。
