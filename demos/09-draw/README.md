# 多光标拖框与逐字排版

来自「夏夏的AI灵感」2026-11-12 发布的《多光标并行绘制》。本包为独立复现，演示窗口长 4.60 秒。

## 从这里开始

1. 完整解压 ZIP，保留目录结构。
2. 双击 index.html，用浏览器打开。可以暂停、重播或拖动进度条。
3. 把本目录与「提示词.txt」一起交给 AI。先说要改哪个动作、颜色或文字，再对照预览检查。

## 画面与时间

用 18 个有稳定颜色的光标分头描出卡片、排标题和画插图。每个指针的尖端跟着自己正在画的线走。

源工程为「Agent 集群 v9」。时钟从 0.000 秒取到 4.600 秒。设置在 settings.js，speed 为 1 表示原速，0.5 表示半速。

依据发布版的动作和时序独立实现。使用包内自绘的示例网页与人物，未包含浏览器扩展或原站快照。

## 工具、插件与实现

HTML、SVG、Canvas 2D、原生 JavaScript。原片的网页重绘参考 Swarm Rebuild；这个离线包直接在浏览器中运行。

[原片参考的 Swarm Rebuild](https://github.com/DhvanilPatel/swarm-cursors)

这个文件夹只绘制内置示例，无需装扩展。要研究原片使用的网页重绘插件，可从上面的作者项目了解。

## 修改和嵌入

主绘制入口在 effect.js。用文本编辑器打开文件即可改，刷新浏览器就能检查。player.js 负责播放和定位，和绘图逻辑独立。

把完整组件目录放进自己的静态网站，使用 iframe 能隔开样式、动画时钟和点击事件。将路径换成组件的实际位置。

~~~html
<iframe src="./09-draw/index.html" title="多光标拖框与逐字排版" loading="lazy" style="width:100%;height:640px;border:0"></iframe>
~~~

## 检查自己的改版

从头播放，确认该动作有起点、过渡和稳定状态。暂停后拖到中段，再次回到同一位置应得到一致的姿势。调整速度后，确认轨迹与先后次序仍然一致。

## 复刻提示词

用 18 个有稳定颜色的光标分头描出卡片、排标题和画插图。每个指针的尖端跟着自己正在画的线走。 采用纸色、墨绿、朱红和各自的光标颜色，给出可离线拖动进度的独立预览。
