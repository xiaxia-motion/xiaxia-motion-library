# 夏夏的AI灵感 · 动效源码库

18 个视频主题，146 组独立动效。按视频找到喜欢的那一组，下载源码包即可单独预览。

1. 在下表打开对应笔记。
2. 在动效名称下点「下载源码 ZIP」。解压后双击 index.html。
3. 想交给 AI 改颜色、节奏或交互，可以把整个文件夹和里面的「提示词.txt」一起交给它。

每个包都附有中文使用说明、调用工具、技术参数和许可。28 个教程组件，以及表现几何、冰蓝拟物和黑白极简三期共 45 个 UI 组件，均附可直接操作的版本。
