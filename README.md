## 三步上手

1. **想直接看效果 / 手机体验**：点上方 **[打开「夏夏动效在线展馆」](https://xiaxia-motion.github.io/xiaxia-motion-library/)**，按期筛选或搜索关键词，点开即可直接操作体验。
2. **想拿源码到本地运行**：在下表点进对应期数的「源码目录」，点击某组动效的「下载源码 ZIP」，解压后双击 `index.html` 即可断网运行。
3. **想让 AI 帮你改成自己的配色和文案**：在展馆里一键复制「提示词」，或把解压后的整个文件夹连同里面的 `提示词.txt` 一起发给任意 AI 编程工具即可。
